# Personal Portfolio - Muhammad Ari Fikrianto 🚀

Selamat datang di repositori website personal saya! Ini adalah website portofolio modern dan minimalis yang saya bangun untuk memperkenalkan diri dan mengumpulkan semua tautan media sosial saya dalam satu tempat yang profesional.

## 👨‍💻 Tentang Pembuat
**Muhammad Ari Fikrianto (Ari)**
Mahasiswa Politeknik Keuangan Negara STAN (Manajemen Keuangan Negara) yang memiliki ketertarikan di dunia *Web Development* dan menulis novel fiksi. Saya percaya bahwa deretan angka dan barisan kode sama-sama menyimpan teka-teki yang menarik, dan saya memadukan logika dari kode serta imajinasi dari sastra.

## ✨ Fitur Utama
- **Single Page Application:** Semua kode (HTML, CSS, JS) dioptimalkan dan disatukan (termasuk Tailwind via CDN) agar sangat mudah untuk di- *deploy*.
- **Desain Modern & Responsif:** Menggunakan paduan warna *Deep Sea Blue* dan *Neon Yellow* yang tampil proporsional di Desktop, Tablet, maupun Mobile.
- **Animasi Halus (AOS):** Interaksi dinamis saat di-*scroll* berkat library Animate on Scroll (AOS).
- **Social Media Hub:** Akses langsung ke platform YouTube, Instagram, X (Twitter), Telegram, dan GitHub.

## 🛠️ Teknologi yang Digunakan
- **HTML5**
- **Tailwind CSS** (via CDN)
- **Vanilla JavaScript** (DOM Manipulation untuk efek Navbar)
- **AOS (Animate on Scroll)** (Library Animasi CSS)
- **Google Fonts** (Space Grotesk & Inter)
